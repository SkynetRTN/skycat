# Security policy

## Supported versions

Security fixes are applied to the active development branch and to the latest
GitHub-hosted package release when a release exists.

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities.

Report security concerns privately to James Atkisson at `james@atkisson.net`.
Include:

- affected commit, tag, or release artifact;
- a short description of the issue;
- reproduction steps or proof of concept, if available;
- whether credentials, source data, or catalog database contents may be exposed.

Expected response: acknowledgement within seven days, followed by triage and a
fix or mitigation plan when the report is reproducible.
